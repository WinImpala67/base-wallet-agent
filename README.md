# Base Wallet Agent

An AI agent project built around Base.

## About

Base Wallet Agent is a learning project focused on using AI agents with Base blockchain tools.

## Goals

* Learn how AI agents interact with Base
* Explore Base MCP
* Read wallet information
* Understand blockchain transactions
* Build safe user-confirmed actions

## Planned Features

* Wallet information
* Balance checks
* Transaction preparation
* User confirmation
* Base blockchain interactions

## Status

🚧 Work in progress

This project is being built step by step while learning Base and AI agent development.
